1.3.0-rc.6 — Guided setup and Unity 6.6 compatibility

• Added a guided Setup window that checks DOTween, Unity UI/TextMesh Pro and TMP Essential Resources, with shortcuts to the official installation tools.
• Sample-launch buttons now become available when the required dependencies and text resources are ready.
• Improved UI position and sprite color animation compatibility with standard DOTween installations; optional DOTween UI/Sprite extensions are no longer required.
• Improved initial import behavior when required dependencies have not yet been installed.
• Updated recipe asset navigation and Editor preview cleanup for Unity 6.6.
• The Animation Gallery supports both legacy input and the Input System without changing your project's input settings.
• Updated installation guidance and included Unity UI package dependency information for easier setup.

Requirements: Unity 6.6 (6000.6.0f1), DOTween Free runtime 1.3.030 or newer, Unity UI/TextMesh Pro and TMP Essential Resources for the gallery. DOTween is installed and licensed separately; it is not included.
