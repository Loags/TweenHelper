# External dependencies

DOTween (HOTween v2), by Demigiant, is required and installed separately. DOTween binaries, source, modules and license files are not redistributed in this package. Obtain and license it from [Demigiant](https://dotween.demigiant.com/) or its [Unity Asset Store listing](https://assetstore.unity.com/packages/tools/animation/dotween-hotween-v2-27676).

Unity UI (uGUI), TextMesh Pro and TMP Essential Resources are installed through Unity separately. Their fonts, shaders and package files are not bundled in this archive. Demo text uses the installed TMP resources and Unity's built-in UI font; the sample requires those resources to be available.
