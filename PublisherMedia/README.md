# Tween Helper Publisher media

This repository-level directory is the canonical destination for final Asset Store upload media. It is outside the Unity project and can never enter the customer `.unitypackage` accidentally.

## Retained source artwork

The approved 1.0 source artwork remains under:

```text
TweenHelper/Assets/_Project/TweenHelperDevelopment/PublisherPortal/Branding
```

Those source files are development-only Unity assets. Do not upload the retired 2D/3D showcase captures and do not copy source artwork into `Assets/Loags/TweenHelper`.

## Final delivery structure

Create these folders when media production begins:

```text
PublisherMedia/
├── Images/
├── MarketingReel/
└── Tutorial/
```

Capture final gallery and Editor-tool footage with Unity Recorder `5.1.7`. Keep both videos caption-only. Confirm the Publisher Portal's current dimensions, duration limits, codecs, and file-size limits before exporting.
